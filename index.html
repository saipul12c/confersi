Pertanyaan Umum (FAQ)

Panduan & jawaban seputar penggunaan Conferti

❓ Kenapa harus menggunakan format WebP untuk website?

WebP adalah format standar emas web masa kini dari Google. Ukurannya 25%–35% lebih hemat dari JPG/PNG pada ketajaman yang sama, mendukung transparansi alpha, dan loading lebih instan sehingga skor Google PageSpeed website Anda meningkat tajam.

❓ Kapan sebaiknya memilih AVIF dibandingkan WebP?

AVIF berbasis video codec AV1 dengan kompresi hingga 50% lebih kecil dari JPG dan 20% lebih hemat dari WebP pada foto kompleks. Gunakan AVIF untuk ukuran file paling minim, atau gunakan WebP untuk kecepatan kompresi kilat dan dukungan universal 97%+ peramban.

❓ Apakah transparansi (PNG transparan) tetap utuh saat diubah ke WebP?

Ya, 100% terjaga! WebP sepenuhnya mendukung transparansi 8-bit alpha channel. Logo, stiker, dan ikon transparan Anda akan tetap bersih tanpa latar belakang, namun dengan ukuran file jauh lebih ringkas.

❓ Apakah file saya aman dan rahasia? Apakah diunggah ke server?

100% Privat & Aman! Conferti bekerja dengan arsitektur Zero-Upload. Pemrosesan gambar dan video murni dilakukan oleh memori dan kartu grafis browser Anda sendiri. Tidak ada satu pun bit data yang dikirim ke internet.

❓ Mengapa ukuran file sekarang dijamin pasti berkurang dan tidak bertambah?

Conferti menggunakan formula bitrate adaptif cerdas yang mengukur bitrate bawaan file asli Anda. Target bitrate encoding selalu dikunci di bawah bitrate aslinya (misalnya ~65% pada kualitas 80%), sehingga file dijamin selalu berkurang dan tidak akan membengkak.

❓ Berapa nilai slider "Kualitas Kompresi" yang paling disarankan?

Untuk sebagian besar website, preset ⚖️ Seimbang (70%) adalah yang terbaik (hemat 50%–70% tanpa penurunan visual kentara). Gunakan 💎 Standar (80%) untuk foto portfolio beresolusi tinggi, atau 🚀 Ekstrem (55%) untuk performa loading super cepat.

❓ Kapan tombol "Unduh Semua" dan "Unduh ZIP" baru aktif?

Tombol unduh massal baru aktif setelah seluruh file antrean selesai dikonversi 100% agar paket unduhan Anda lengkap. Jika membutuhkan satu file lebih cepat, tombol "Unduh" per baris dapat langsung diklik kapan saja.

❓ Kapan harus menggunakan "Web Video (.webm)" vs "Animasi WebP (.webp)"?

• Web Video (.webm): Untuk video rapat, presentasi, atau tutorial dengan audio penuh.
• Animasi WebP (.webp): Untuk stiker animasi, hero banner, atau preview looping tanpa suara pengganti GIF yang boros kuota.

❓ Bagaimana cara kerja fitur "Maks Dimensi" (Resize)?

Fitur ini secara otomatis mengecilkan foto kamera resolusi tinggi (misal 4K/8K) ke ukuran maksimal layar web (1920px atau 1280px) secara proporsional sebelum dikompresi, memangkas ukuran file hingga 80% ekstra tanpa pecah.

❓ Apakah Conferti mampu memproses ratusan file atau file >1 GB?

Sangat sanggup! Antrean sekuensial hemat memori segera membersihkan alokasi canvas RAM/VRAM setelah setiap file selesai, menjaga peramban tetap ringan dan bebas dari tab crash.
