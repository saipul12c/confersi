Kenapa menggunakan format .WebP untuk Website?

  • Untuk Gambar: Ya, tepat sekali! WebP adalah format standar emas untuk web saat ini. Ukurannya 25% - 35% lebih kecil dari JPG/PNG tanpa buram dan mendukung transparansi.
  • Untuk Video: Format video standar web adalah WebM atau MP4. Namun, mengonversi video menjadi Animasi WebP (.webp) sangat populer untuk menggantikan file GIF yang berat pada website (animasi halus, looping, ukuran jauh lebih ringan). Anda juga bisa mengambil Poster Cover thumbnail video ke .webp.
