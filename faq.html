Pertanyaan yang Sering Diajukan (FAQ)

Panduan komprehensif seputar pengoptimalan WebP, AVIF, WebM, implementasi kode HTML, keamanan privasi, dan tips kompresi media terbaik di Conferti.

🖼️ Format Gambar & Video Web

1 Kenapa format .WebP sangat dianjurkan untuk website modern?

WebP adalah format standar web modern yang dikembangkan Google. WebP menghasilkan ukuran file 25% hingga 35% lebih hemat dibandingkan JPG atau PNG pada kualitas visual yang sama. Format ini mendukung kompresi lossy, lossless, transparansi (alpha channel), serta animasi. Menggunakan WebP secara nyata mempercepat waktu muat halaman dan meningkatkan skor Google Core Web Vitals (LCP).

2 Kapan sebaiknya memilih AVIF dibandingkan WebP?

AVIF (.avif) adalah format generasi termutakhir berbasis video codec AV1. AVIF mampu mengompresi gambar hingga 50% lebih kecil dari JPEG dan sekitar 20% lebih hemat dari WebP, terutama pada foto dengan gradasi warna halus atau tekstur rumit. Pilih AVIF jika prioritas utama Anda adalah ukuran file sekecil mungkin. Pilih WebP jika Anda menginginkan proses konversi super kilat dan kompatibilitas peramban yang sangat universal (>97%).

3 Apakah transparansi (saluran Alpha / PNG transparan) tetap utuh saat diubah ke WebP?

Ya, 100% terjaga! WebP sepenuhnya mendukung transparansi (8-bit alpha channel) baik pada mode lossy maupun lossless. Logo, stiker, ikon, atau ilustrasi tanpa latar belakang akan tetap transparan secara sempurna dengan ukuran file yang jauh lebih kecil dibandingkan PNG asli.

4 Bagaimana cara memasang gambar WebP & AVIF di kode HTML dengan fallback aman?

Gunakan tag HTML5 <picture>. Peramban modern akan otomatis memilih format terbaik yang didukungnya:

<picture>
  <source srcset="gambar.avif" type="image/avif">
  <source srcset="gambar.webp" type="image/webp">
  <img src="gambar.jpg" alt="Deskripsi gambar" loading="lazy">
</picture>

5 Kapan harus memilih "Web Video (.webm)" vs "Animasi WebP (.webp)"?

• Web Video (.webm): Format video standar web Google lengkap dengan audio (suara) dan durasi utuh. Sangat cocok untuk rekaman webinar, video rapat, presentasi, atau tutorial website.

• Animasi WebP (.webp): Klip cuplikan pendek yang berputar tanpa henti (looping) tanpa suara. Format ini dirancang khusus untuk menggantikan file GIF jadul yang berat, sangat ideal untuk ilustrasi animasi, stiker, atau preview hero banner.

6 Bagaimana cara membuat video WebM berputar otomatis sebagai background website (Hero Video)?

Gunakan tag HTML5 dengan atribut autoplay muted loop playsinline. Sertakan atribut poster menggunakan cover WebP untuk tampilan awal instan sebelum video berputar:

<video autoplay muted loop playsinline poster="video-poster.webp" class="w-full h-full object-cover">
  <source src="video.webm" type="video/webm">
  <source src="video.mp4" type="video/mp4">
</video>
⚙️ Algoritma Kompresi & Kontrol Kualitas

7 Mengapa ukuran file di Conferti dijamin pasti berkurang dan tidak bertambah?

Conferti menggunakan formula bitrate adaptif cerdas. Sebelum mengonversi video, sistem menghitung bitrate asli dari file Anda ($(\text{File Size} \times 8) / \text{Durasi}$). Target bitrate kompresi dikunci secara proporsional di bawah bitrate aslinya (misalnya ~65% pada kualitas 80%, atau ~38% pada preset Ekstrem 55%), sehingga ukuran file dijamin selalu berkurang dan tidak akan pernah membengkak lagi.

8 Berapa nilai slider "Kualitas Kompresi" yang paling disarankan?

• 💎 Standar (80%): Sangat cocok untuk fotografi profesional, banner beresolusi tinggi, atau gambar dengan teks tajam.

• ⚖️ Seimbang (70%): Pilihan paling direkomendasikan untuk artikel blog, e-commerce, dan katalog web. Hemat 50%–70% dengan ketajaman visual prima.

• 🚀 Ekstrem (55%): Pilihan terbaik jika target Anda adalah performa kecepatan mutlak pada jaringan seluler/3G/4G hemat kuota.

9 Bagaimana cara kerja fitur "Maks Dimensi" (Resize) gambar?

Banyak foto dari kamera smartphone beresolusi 4000x3000 piksel yang sangat boros jika ditampilkan di layar laptop atau ponsel. Fitur "Maks Dimensi" secara cerdas mengecilkan resolusi terpanjang ke batas yang Anda pilih (misal 1920px untuk desktop atau 1280px untuk konten artikel) secara proporsional sebelum dikompresi. Hal ini secara instan memotong ukuran file hingga 80% ekstra!

10 Apakah Conferti sanggup menangani ratusan file atau file besar di atas 1 GB?

Sangat sanggup! Conferti menggunakan sistem antrean sekuensial (satu demi satu) dan teknik pembersihan memori canvas (canvas.width = 0) secara langsung setiap kali file selesai. Dengan begitu, pemakaian RAM browser tetap stabil di bawah batas wajar dan tidak akan menyebabkan tab peramban macet (*out-of-memory crash*).

🔒 Keamanan, Lisensi, & Pengunduhan

11 Apakah file sensitif saya aman? Apakah ada data yang dikirim ke server?

100% Aman & Privat! Conferti bekerja dengan arsitektur murni Client-Side. Semua pemrosesan citra dan video berlangsung langsung di peramban web dan kartu grafis (GPU/RAM) komputer Anda menggunakan WebAssembly, HTML5 Canvas, dan MediaRecorder API. Tidak ada satu kilobyte pun data yang diunggah ke internet atau server pihak ketiga.

12 Kenapa tombol "Unduh Semua (ZIP)" baru aktif setelah seluruh file selesai?

Tombol unduh massal dirancang sengaja aktif setelah seluruh antrean selesai diproses 100% agar paket unduhan Anda lengkap dan tidak ada file yang hilang atau terlewat. Jika Anda membutuhkan file tertentu lebih cepat saat antrean masih berjalan, Anda tetap bisa mengklik tombol "Unduh" satuan pada baris file yang sudah selesai duluan.

13 Apa perbedaan tombol "Unduh Semua (ZIP)" dengan "Unduh Semua (File Langsung)"?

Tombol Unduh Semua (ZIP) mengemas semua file hasil konversi ke dalam satu file arsip .zip yang rapi. Sementara Unduh Semua (File Langsung) mengunduh setiap file asli langsung ke folder Downloads komputer Anda secara berurutan otomatis tanpa perlu mengekstrak ZIP lagi.

14 Mengapa peramban meminta izin "Izinkan mengunduh banyak file" saat klik Unduh Langsung?

Peramban modern (Chrome, Edge, Firefox) memiliki fitur perlindungan keamanan bawaan yang mencegah situs web mengunduh berkas secara otomatis berulang-ulang tanpa izin pengguna. Saat pop-up peramban muncul, cukup klik "Izinkan" (Allow) satu kali agar seluruh berkas hasil konversi terunduh secara mulus ke folder Downloads Anda.

15 Apakah Conferti sepenuhnya gratis dan adakah batasan kuota harian?

100% Gratis dan Tanpa Batas! Conferti dibuat sebagai alat utilitas terbuka bebas biaya tanpa registrasi, tanpa langganan, tanpa watermark, dan tanpa batasan kuota harian. Anda bebas mengonversi file sebanyak apa pun kapan pun Anda butuhkan.
